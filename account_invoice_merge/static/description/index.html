Account invoice merge

This module facilitates the merging of multiple invoices in draft state that share the same partner into a single invoice, and cancels those multiple invoices

Invoice Merge Conditions

Make sure:

  • Type should be the same (Customer Invoice, Supplier Invoice, Customer Refund or Supplier Refund)
  • Partner should be the same
  • Currency should be the same
  • Account receivable account should be the same

Invoice Merge

Go to a invoice tree view, select several invoices and click expand the action button and click ‘Merge Partner Invoice’.

Set invoice Date

Upon clicking 'Merge Partner Invoice', a popup displays the necessary conditions to be checked before merging invoices, along with the option to set an invoice date for the merged invoices.

Merged Invoices

When 'Merge Invoices' is clicked within the popup, the selected invoices will be merged into a single invoice, and the state of the merged invoices will be changed to 'cancelled'.
